Vue d'ensemble des vulnérabilités identifiées et de leur impact sur l'activité de l'agence.

Analyse Détaillée Point par Point

Examen technique et preuves constatées sur les serveurs de production.

01

Protection contre le Détournement de Clic (Clickjacking)

Vulnérabilité Écran
Risque pour l'activité de Nelly : Un site tiers peut encapsuler l'ancien site Nell'Immo dans une fenêtre invisible (iframe) et superposer de faux boutons pour intercepter des demandes de contact ou faire exécuter des actions à des prospects à leur insu.
Ancien Site (www.nellimmo.fr)

Aucun en-tête X-Frame-Options ni directive de sécurité de contenu (CSP).

# En-têtes constatés :
HTTP/1.1 200 OK
server: Apache
X-Frame-Options: [ABSENT]
Content-Security-Policy: [ABSENT]
Nouveau Site (nellimmo.vercel.app)

Blocage formel configuré au niveau du serveur. Tout encadrement externe est immédiatement rejeté par les navigateurs.

# En-têtes constatés :
HTTP/1.1 200 OK
X-Frame-Options: DENY
Content-Security-Policy: frame-ancestors 'none';
02

Sécurité des Cookies de Session (Vol d'Accès)

Confidentialité & RGPD
Risque pour l'activité de Nelly : Si Nelly ou un client utilise le site depuis un réseau non sécurisé (Wi-Fi de gare, d'hôtel ou de salon immobilier), un tiers peut capturer le badge de session en clair et usurper l'accès sans avoir besoin du mot de passe.
Ancien Site (www.nellimmo.fr)

Le cookie de session PHP est envoyé sans protection contre le vol par script ni obligation de chiffrement.

# En-tête Set-Cookie constaté :
set-cookie: PHPSESSID=8e9fit...; path=/
HttpOnly: ABSENT (lisible par script)
Secure:   ABSENT (peut circuler en non chiffré)
Nouveau Site (nellimmo.vercel.app)

Cookie d'authentification entièrement verrouillé : inaccessible aux scripts externes et limité aux connexions chiffrées.

# En-tête Set-Cookie constaté :
set-cookie: nellimmo_cockpit_auth=...; Path=/;
HttpOnly: OUI (protégé contre le vol)
Secure:   OUI (HTTPS obligatoire)
SameSite: Lax
03

Contrôle d'Accès au Panneau d'Administration (Cockpit)

Accès Données Sensibles
Risque pour l'activité de Nelly : L'exposition publique d'une page de connexion permet aux robots de tester des milliers de mots de passe automatiquement (force brute), menaçant les dossiers Loi ALUR (avis d'impôt, pièces d'identité) et le registre des clés d'appartements.
Ancien Site (www.nellimmo.fr)

Aucune barrière réseau à l'entrée. Les requêtes sur les espaces d'administration reçoivent un accord direct de chargement de page.

# Comportement observé :
HTTP/1.1 200 OK
Accès direct à la page de connexion
Aucun filtrage réseau préalable
Nouveau Site (nellimmo.vercel.app)

Protection par Middleware Edge : blocage strict avec code HTTP 401 Unauthorized pour toute personne non habilitée.

# Test réel sur /cockpit :
HTTP/1.1 401 Unauthorized
Www-Authenticate: Basic realm="Cockpit"
X-Robots-Tag: noindex, nofollow, noarchive
04

Chiffrement Obligatoire des Échanges (HSTS)

Chiffrement Réseau
Risque pour l'activité de Nelly : Sans politique HSTS stricte, un pirate sur un réseau intermédiaire peut forcer le déclassement de la communication vers du HTTP non sécurisé et lire en clair les formulaires d'estimation ou de contact remplis par les clients.
Ancien Site (www.nellimmo.fr)

Aucun en-tête HSTS n'est émis. Le navigateur n'a aucune consigne d'obligation stricte du protocole HTTPS.

# En-tête HSTS :
Strict-Transport-Security: [ABSENT]
--> Possibilité de rétrogradation en HTTP non chiffré
Nouveau Site (nellimmo.vercel.app)

Directive HSTS active sur 2 ans (63 072 000 secondes) avec intégration aux listes de préchargement mondiales (Preload).

# En-tête HSTS constaté :
Strict-Transport-Security: 
  max-age=63072000; includeSubDomains; preload
05

Cloisonnement des Requêtes Inter-Domaines (CORS)

Pillage Commercial
Risque pour l'activité de Nelly : Une règle CORS trop permissive (wildcard *) permet à des sites concurrents ou à des robots de collecter automatiquement le catalogue des annonces et les données de contact directement depuis le navigateur de leurs visiteurs.
Ancien Site (www.nellimmo.fr)

Le serveur transmet une autorisation générale sans restriction d'origine sur des réponses de page d'accueil.

# En-têtes constatés :
access-control-allow-origin: *
access-control-allow-headers: Authorization, Content-Type
--> Accès ouvert à l'ensemble des domaines tiers
Nouveau Site (nellimmo.vercel.app)

Suppression de tout wildcard non justifié. Les points d'entrée applicatifs exigent une session active et rejettent les accès tiers non autorisés.

# Test sur point d'entrée privé :
curl -i https://nellimmo.vercel.app/api/settings/ai-key
HTTP/1.1 401 Unauthorized
{"error":"unauthorized"}
06

Divulgation d'Informations Techniques sur l'Infrastructure

Reconnaissance d'Attaque
Risque pour l'activité de Nelly : Afficher publiquement la version exacte d'un serveur ou d'un moteur obsolète permet aux outils d'analyse automatisés de cibler directement les failles de sécurité non corrigées sur cette version spécifique.
Ancien Site (www.nellimmo.fr)

L'ancien hébergement expose le nom du serveur Apache, la version interne de 2020 et les identifiants de cluster de répartition.

# En-têtes exposés :
server: Apache
x-bobcat-version: kitty.pryde.20201020.rev2 (octobre 2020)
x-server-id: cluster8-w3
x-lbi-loadbalancer: cluster8-lb1
Nouveau Site (nellimmo.vercel.app)

L'infrastructure Vercel Edge masque toute référence logicielle interne ou numéro de version système.

# En-têtes constatés :
Server: Vercel
X-Content-Type-Options: nosniff
--> Aucune version logicielle interne n'est divulguée
07

Obsolescence de Dépendance : jQuery 1.10.1 (Mai 2013)

Vulnérabilité Applicative
Risque pour l'activité de Nelly : Cette version de jQuery (13 ans d'ancienneté) est affectée par des failles connues de type XSS (CVE-2020-11022, CVE-2019-11358) pouvant permettre l'altération de formulaires ou la redirection de prospects.
Ancien Site (www.nellimmo.fr)

Chargement direct de bibliothèques tierces obsolètes hébergées sur des dépôts publics non mis à jour.

# Code source prélevé :
<script src="//ajax.googleapis.com/ajax/libs/
  jquery/1.10.1/jquery.min.js"></script>
<script src="//ajax.googleapis.com/ajax/libs/
  jqueryui/1.10.3/jquery-ui.min.js"></script>
Nouveau Site (nellimmo.vercel.app)

Aucune utilisation de jQuery. L'interface repose sur React 19 qui neutralise nativement les injections de contenu via son système d'encodage strict.

# Analyse applicative :
jQuery : Absent (0%)
Moteur d'interface : React 19 / Next.js 16
Protection XSS : Encodage automatique du rendu
08

Sécurité de la Messagerie : Risque d'Usurpation (Email Spoofing)

Fraude & Usurpation
Risque pour l'activité de Nelly : En l'absence de politique DMARC stricte, un tiers peut envoyer des emails affichant comme expéditeur contact@nellimmo.fr ou nelly@nellimmo.fr. C'est le vecteur classique de l'arnaque au faux RIB lors d'un appel de fonds pour un séquestre ou des honoraires.
Ancien Site & Domaine Actuel

L'enregistrement SPF actuel se termine par ?all (neutre, ne bloque rien) et l'enregistrement DMARC est inexistant.

# Résolution DNS en direct :
SPF : v=spf1 include:la-boite-immo.fr ?all (?all = neutre)
DMARC : _dmarc.nellimmo.fr -> Le nom DNS n'existe pas
--> Les serveurs de messagerie ne rejettent pas les faux mails
Nouveau Projet & DNS Cibles

Recommandation d'application des standards stricts lors du rattachement du domaine : DMARC en politique de rejet (p=reject) et durcissement SPF (-all).

# Configuration préconisée :
SPF : v=spf1 include:... -all (-all = rejet strict)
DMARC : v=DMARC1; p=reject; rua=mailto:contact@nellimmo.fr
DKIM : Signature cryptographique 2048 bits
